# 📊 Sales Data Analysis

## 📌 Project Overview

This project analyzes sales data to understand business performance and generate meaningful insights.

The analysis focuses on:

- Total Sales
- Sales by Category
- Sales by Region
- Product Performance
- Monthly Sales Trends

---

## 🎯 Project Objectives

The objectives of this project are:

1. Analyze overall sales performance.
2. Identify high-performing product categories.
3. Compare sales across different regions.
4. Identify top-performing products.
5. Analyze monthly sales trends.
6. Generate insights to support business decisions.

---

## 🛠️ Tools Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

- GitHub
